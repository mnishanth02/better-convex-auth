# Templates Folder - Usage Guide

## Purpose

The `packages/z-auth/templates/` folder contains **starter templates** for setting up a Convex backend with authentication in your application. These files are meant to be **copied** into your app's `convex/` directory.

## ✅ Status: ACTIVELY USED & PROPERLY CONFIGURED

The templates folder is:
- ✅ **Exported** in package.json via `"./templates/*": "./templates/*"`
- ✅ **Referenced** in documentation (copilot-instructions.md, README.md)
- ✅ **Updated** to match the actual working implementation in `apps/web/convex/`

## Template Files

### 1. `convex.config.ts` (18 lines)
**Purpose:** Configures Convex components (Better Auth + Resend)

```typescript
import betterAuth from "@convex-dev/better-auth/convex.config";
import resend from "@convex-dev/resend/convex.config";
import { defineApp } from "convex/server";

const app = defineApp();
app.use(betterAuth);
app.use(resend);
export default app;
```

**Status:** ✅ Matches actual implementation

---

### 2. `auth.ts` (37 lines)
**Purpose:** Sets up authentication providers using `@convex-dev/auth`

**Key Features:**
- OAuth providers (GitHub, Google, Apple)
- Simple configuration with `convexAuth()`
- Comments explaining how to add email/password auth
- Exports: `auth`, `signIn`, `signOut`, `store`

**Status:** ✅ Updated to match actual implementation

---

### 3. `http.ts` (31 lines)
**Purpose:** Registers HTTP routes for authentication

**Key Features:**
- Registers `/auth/*` endpoints via `auth.addHttpRoutes(http)`
- Optional Resend webhook configuration (commented out)
- Clean, minimal implementation

**Status:** ✅ Updated to match actual implementation

---

### 4. `schema.ts` (75 lines)
**Purpose:** Defines database schema for authentication

**Required Tables:**
- `users` - User accounts with email, name, image, role
- `sessions` - Active user sessions
- `accounts` - OAuth and password authentication data
- `verifications` - Email verification tokens

**Optional:**
- `passwordResetTokens` - For password reset functionality (commented out)

**Status:** ✅ Updated to match actual implementation with correct field names and indexes

## How to Use Templates

### Method 1: Manual Copy (Recommended for Customization)

```bash
# From your app directory (e.g., apps/web/)
cp ../../packages/z-auth/templates/*.ts convex/
```

Then customize each file for your app's needs.

### Method 2: Copy from node_modules (After Installation)

```bash
# From your app directory
cp node_modules/@workspace/z-auth/templates/* convex/
```

### Method 3: Programmatic Access (Future Enhancement)

```typescript
// Not yet implemented, but could add:
import { copyTemplates } from "@workspace/z-auth/templates";
await copyTemplates("./convex");
```

## Required Dependencies

After copying templates, install these dependencies in your **app** (not in z-auth):

```bash
# In apps/web/ or your app directory
pnpm add @convex-dev/auth @convex-dev/better-auth @convex-dev/resend
pnpm add @auth/core  # For OAuth providers
```

---

## Environment Variables

After setup, configure these in your app's `.env.local`:

```env
# Convex (auto-generated by `npx convex dev`)
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud

# Site URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# OAuth Providers (optional)
AUTH_GITHUB_ID=your_github_client_id
AUTH_GITHUB_SECRET=your_github_client_secret
AUTH_GOOGLE_ID=your_google_client_id
AUTH_GOOGLE_SECRET=your_google_client_secret

# Email Service (optional)
RESEND_API_KEY=re_xxxxx
RESEND_WEBHOOK_SECRET=whsec_xxxxx
```

## Common Customizations

### Add Email/Password Authentication

In `auth.ts`:
```typescript
import { Password } from "@convex-dev/auth/providers/Password";

export const { auth, signIn, signOut, store } = convexAuth({
  providers: [
    GitHub,
    Google,
    Password, // Add this
  ],
});
```

### Add More OAuth Providers

```typescript
import Discord from "@auth/core/providers/discord";
import Facebook from "@auth/core/providers/facebook";

export const { auth, signIn, signOut, store } = convexAuth({
  providers: [
    GitHub,
    Google,
    Discord,
    Facebook,
    // ... more providers
  ],
});
```

### Add Custom Tables

In `schema.ts`:
```typescript
export default defineSchema({
  // ... auth tables ...
  
  // Your custom tables
  posts: defineTable({
    title: v.string(),
    content: v.string(),
    authorId: v.string(),
    createdAt: v.number(),
  }).index("by_author", ["authorId"]),
});
```

## Integration with @workspace/z-auth

### Frontend Setup (No Templates Needed)

```typescript
// lib/auth/setup.ts
import { createAuth } from "@workspace/z-auth/nextjs";

export const auth = createAuth({
  convexUrl: process.env.NEXT_PUBLIC_CONVEX_URL!,
});

export const {
  AuthProvider,
  useAuth,
  useSession,
  components,
} = auth;
```

### API Routes (No Templates Needed)

```typescript
// app/api/auth/[...all]/route.ts
export { GET, POST } from "@workspace/z-auth/nextjs/handler";
```

**Note:** The templates are ONLY for the Convex backend setup. Frontend integration uses the z-auth package directly.
