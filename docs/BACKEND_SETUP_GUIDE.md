# Backend Setup Guide

## Overview

This guide explains how to set up your own Convex backend with Better Auth integration, making your app independent from the shared `@workspace/backend` package.

## Why App-Specific Backends?

**Benefits:**
- ✅ **Independence**: Each app controls its own database and functions
- ✅ **Customization**: Tailor the backend to your app's needs
- ✅ **Scalability**: Separate deployments for better performance
- ✅ **Flexibility**: Different apps can use different Convex features
- ✅ **Isolation**: Changes in one app don't affect others

## Quick Start

### Step 1: Initialize Convex in Your App

```bash
cd apps/your-app
npx convex dev
```

This creates:
- `convex/` directory
- `.env.local` with `NEXT_PUBLIC_CONVEX_URL`
- `convex/_generated/` with TypeScript types

### Step 2: Copy Template Files

Copy the template files from `@workspace/auth` to your app's `convex/` directory:

```bash
# From your app directory
cp node_modules/@workspace/auth/templates/* convex/
```

Or manually create these files in `convex/`:
- `convex.config.ts` - Convex app configuration
- `auth.ts` - Better Auth setup
- `http.ts` - HTTP routes for auth endpoints
- `schema.ts` - Database schema

### Step 3: Install Dependencies

Add required packages to your app:

```bash
pnpm add @auth/core @convex-dev/better-auth @convex-dev/resend convex-helpers
```

### Step 4: Configure Environment Variables

Add to your app's `.env.local`:

```env
# Convex (auto-generated by convex dev)
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud

# Your app URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Server-side only
CONVEX_DEPLOYMENT=dev:your-project
SITE_URL=http://localhost:3000

# OAuth (optional)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret

# Email service (optional)
RESEND_API_KEY=your-resend-api-key
```

### Step 5: Update Imports

Change imports from shared backend to local convex:

**Before:**
```typescript
import { api } from "@workspace/backend/convex/_generated/api";
import type { Id } from "@workspace/backend/convex/_generated/dataModel";
```

**After:**
```typescript
import { api } from "@/convex/_generated/api";
import type { Id } from "@/convex/_generated/dataModel";
```

### Step 6: Remove Shared Backend Dependency

Update your `package.json`:

```diff
{
  "dependencies": {
-   "@workspace/backend": "workspace:*",
    "@workspace/auth": "workspace:*",
    // ... other dependencies
  }
}
```

Run: `pnpm install`

### Step 7: Start Development

```bash
# Terminal 1: Start Convex
pnpm convex dev

# Terminal 2: Start Next.js
pnpm dev
```

## File Structure

Your app should now have:

```
your-app/
├── convex/
│   ├── convex.config.ts      # Convex configuration
│   ├── auth.ts                # Better Auth setup
│   ├── http.ts                # HTTP routes
│   ├── schema.ts              # Database schema
│   ├── _generated/            # Auto-generated types
│   └── [your-functions].ts   # Your Convex functions
├── app/
│   ├── api/auth/[...all]/route.ts  # Auth API routes (from @workspace/auth)
│   └── ...
├── lib/
│   └── auth.ts                # Auth setup (using @workspace/auth)
├── .env.local                 # Environment variables
└── package.json
```

## Customizing Your Backend

### Adding Custom Functions

Create new files in `convex/`:

```typescript
// convex/posts.ts
import { query, mutation } from "./_generated/server";
import { v } from "convex/values";

export const list = query({
  args: {},
  handler: async (ctx) => {
    return await ctx.db.query("posts").collect();
  },
});

export const create = mutation({
  args: {
    title: v.string(),
    content: v.string(),
  },
  handler: async (ctx, args) => {
    // Get current user
    const user = await authComponent.getAuthUser(ctx);
    if (!user) throw new Error("Not authenticated");

    return await ctx.db.insert("posts", {
      title: args.title,
      content: args.content,
      authorId: user.id,
      createdAt: Date.now(),
    });
  },
});
```

### Extending the Schema

Add your tables to `convex/schema.ts`:

```typescript
export default defineSchema({
  // ... auth tables (users, sessions, etc.)

  // Your custom tables
  posts: defineTable({
    title: v.string(),
    content: v.string(),
    authorId: v.string(),
    createdAt: v.number(),
  })
    .index("by_author", ["authorId"])
    .index("by_created", ["createdAt"]),

  comments: defineTable({
    postId: v.id("posts"),
    authorId: v.string(),
    content: v.string(),
    createdAt: v.number(),
  }).index("by_post", ["postId"]),
});
```

### Customizing Auth Configuration

Edit `convex/auth.ts` to customize:

```typescript
export const createAuth = (ctx: GenericCtx<DataModel>) => {
  return createConvexAuth(ctx, {
    adapter: authComponent.adapter(ctx),
    baseURL: process.env.SITE_URL!,

    // Customize these settings
    emailPassword: {
      enabled: true,
      requireEmailVerification: true,  // Change this
      minPasswordLength: 12,            // Increase security
      maxPasswordLength: 128,
    },

    socialProviders: {
      // Add more providers
      apple: process.env.APPLE_CLIENT_ID ? {
        clientId: process.env.APPLE_CLIENT_ID,
        clientSecret: process.env.APPLE_CLIENT_SECRET!,
      } : undefined,
    },

    session: {
      expiresIn: 60 * 60 * 24 * 30,  // 30 days instead of 7
      updateAge: 60 * 60 * 24,
    },

    // Your custom email templates
    emailVerification: {
      sendVerificationEmail: async (params) => {
        // Custom email template
        await resend.sendEmail(ctx as any, {
          from: "Your App <noreply@yourapp.com>",
          to: params.user.email,
          subject: "🎉 Welcome to Your App!",
          html: customEmailTemplate(params),
        });
      },
    },
  });
};
```

## Deployment

### Deploy to Convex Cloud

```bash
# Deploy your backend
pnpm convex deploy --prod

# Get production URL
# Update NEXT_PUBLIC_CONVEX_URL in production environment
```

### Update Environment Variables

For production, set:
- `NEXT_PUBLIC_CONVEX_URL` to production Convex URL
- `NEXT_PUBLIC_SITE_URL` to your production domain
- All OAuth and email service credentials

## Migration from Shared Backend

If you're migrating from `@workspace/backend`:

### 1. Export Existing Data (Optional)

```bash
# Export from shared backend
cd packages/backend
pnpm convex export --path ./backup
```

### 2. Set Up New Backend

Follow the Quick Start steps above.

### 3. Import Data (Optional)

```bash
# Import to your app's backend
cd apps/your-app
pnpm convex import --path ../../packages/backend/backup
```

### 4. Update All Imports

Use find and replace:
- `@workspace/backend/convex/_generated` → `@/convex/_generated`
- `@workspace/backend` → (remove this dependency)

### 5. Test Thoroughly

- ✅ Sign in/Sign up
- ✅ Session persistence
- ✅ OAuth flows
- ✅ Email verification
- ✅ All custom functions

## Troubleshooting

### "Cannot find module '@/convex/_generated/api'"

**Solution**: Make sure Convex is running: `pnpm convex dev`

### "Missing environment variable: NEXT_PUBLIC_CONVEX_URL"

**Solution**: Run `npx convex dev` to generate `.env.local`

### "Auth endpoints returning 404"

**Solution**: Verify `http.ts` is properly registered and `pnpm convex dev` is running

### TypeScript errors in convex/

**Solution**: Ensure `@auth/core` is installed and Convex has generated types
